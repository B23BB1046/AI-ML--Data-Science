# AI, Machine Learning & Data Science Learning Lab

A growing collection of notebooks, tutorials, and experiments covering AI, machine learning, deep learning, and data science. The repository is intended as a practical learning log: concepts, implementations, and experiments kept together for easy exploration.

## Topics

- **Machine Learning:** core algorithms, model training, and evaluation.
- **Deep Learning:** neural-network experiments and notebook-based labs.
- **AI Tutorials:** introductory concepts and hands-on examples.
- **Computer Vision:** includes a visual-question-answering encoder–decoder lab.

## Repository structure

| Path | Contents |
|---|---|
| `AI-Tutorial/` | AI learning material and examples |
| `Machine_Learning/` | Machine-learning topics and experiments |
| `Deep_Learning/` | Deep-learning material |
| `VQA_Encoder_Decoder_Lab.ipynb` | Encoder–decoder visual question-answering experiment |

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/B23BB1046/AI-ML--Data-Science.git
   cd AI-ML--Data-Science
   ```
2. Create a Python virtual environment.
3. Install the libraries required by the notebook or tutorial you want to run.
4. Open notebooks with Jupyter or Google Colab and follow the cells in order.

## Suggested workflow

- Read the problem statement before running a notebook.
- Record dataset source, preprocessing, and train/validation/test split.
- Include evaluation metrics and a short interpretation of results.
- Keep large datasets, model weights, credentials, and generated artifacts out of Git unless there is a clear reason to version them.
